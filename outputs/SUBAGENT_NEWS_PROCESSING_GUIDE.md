# 뉴스 데이터 처리 서브에이전트 지침서

**작성일**: 2026-07-24  
**목적**: JSON 뉴스 파일의 "요약"과 "필터링 여부" 필드 작성  
**대상 모델**: Claude Haiku 4.5

---

## 작업 개요

각 JSON 파일에 포함된 뉴스 항목들에 대해 다음 두 가지 필드를 작성합니다:

1. **"요약"**: 뉴스 본문의 핵심을 정리한 요약문 (150~200자, 공백 포함)
2. **"필터링 여부"**: 필터링 기준에 따른 Y/N 판정

---

## 필드 작성 기준

### 1. 요약 (Summary)

**길이 요구사항**
- 최소 150자 이상, 200자 이하 (공백 포함)
- 150자 미만이면 ❌ 부족
- 200자 초과이면 ❌ 초과
- 정확한 글자 수는 검증 필수

**내용 요구사항**
- 뉴스 본문에서 가장 중요한 1~2개 사실만 추출
- 제목에 없는 구체적 수치, 시기, 주체를 포함
- 뉘앙스와 맥락 유지 (예: "~다고 주장했다", "~을 우려한다" 등)
- 간결하되 명확한 한국어

**작성 예시**

| 제목 | 본문 요약 | 글자수 검증 |
|---|---|---|
| "한은, 기준금리 2.75%로 인상" | 한국은행은 7월 16일 기준금리를 2.50%에서 2.75%로 올렸으며, 금융통화위원 7명이 모두 인상에 찬성했다. 1분기 국내총소득은 전년 동기보다 13.2% 증가했지만, 제조업 취업자는 9만7000명 감소해 고용과 정반대 신호를 보였다. | ✅ 156자 |

### 2. 필터링 여부 (Y/N Judgment)

**Y (KEEP - 유지) 판정 기준**

다음 카테고리 중 **하나라도 해당**하면 `Y`:

- **반도체·전자 산업**: 반도체, HBM, 메모리, 파운드리, OLED, 반도체 기업/경쟁사 뉴스
- **거시금융 지표·정책**: 금리, 환율, 통화량, CPI, 유가, 수출입, GDP, 안전자산(금값)
- **관세·통상**: 관세협상, FTA, 수출규제, 무역협상 (품목 무관)
- **정부 정책**: 반도체/수출/투자 관련 정부 정책, 세제 지원
- **공급망·물류**: 반도체에 영향 주는 해운비, 물류비, 에너지 수급
- **삼성전자 관련**: 삼성전자 및 계열사(삼성전기, LG디스플레이, SK하이닉스 등) 뉴스

**N (DROP - 제외) 판정 기준**

다음 카테고리에 **명확히 해당**하면 `N`:

- **사회·복지·인구**: 출산율, 저출산, 고령화, 세대격차, 복지
- **개인 생활물가**: 식재료, 식비, 외식비, 교육비, 소비 트렌드
- **문화·예술·스포츠·연예**: 영화, 음악, 스포츠, 연예인 뉴스
- **항공·여행**: 항공사 경영, 항공편, 여행 수요 (단, **본질이 지정학·유가·반도체**라면 Y)
- **부동산·주택**: 아파트 분양가, 전세금, 월세 (단, **거시금융 안정성 이슈**라면 Y)
- **정치·인사**: 정치인 개인사, 인사 임명, 조직개편 (경제정책 내용 없으면)
- **지역행사·CSR**: 지역축제, 기업의 사회공헌 활동

**의심의 이익은 Y**
- 판정이 애매하면 **반드시 Y** 선택
- "혹시 시장 영향이 있을 수도"라고 생각되면 Y
- 정보환경 왜곡을 피하기 위해 보수적 판정

## 작업 프로세스

### 단계 1: 파일 확인
```
처리할 JSON 파일명: [오케스트레이터로부터 전달]
예: 001.json, 002.json, ... (최대 5개)
```

### 단계 2: 각 뉴스 항목 처리

**2-1. 요약 작성**
1. 본문을 읽고 핵심 1~2개 사실 추출
2. 150~200자로 작성
3. 정확한 글자 수 계산 및 검증

**2-2. 필터링 판정**
1. FILTERING_CRITERIA.md의 KEEP/DROP 기준 대조
2. Y 또는 N 선택
3. 의심 사항은 Y로 선택

### 단계 3: JSON 파일 업데이트

```json
{
  "제목": "원문",
  "작성시각": "원문",
  "본문": "원문",
  "요약": "[작성한 요약문]",
  "필터링 여부": "[Y 또는 N]"
}
```

### 단계 4: 자체 검증 (필수)

각 항목마다:
- ✅ 요약이 150~200자 범위인가?
- ✅ 본문의 핵심을 담고 있는가?
- ✅ 필터링 기준에 부합하는 판정인가?
- ✅ 오타나 어색한 표현이 없는가?

검증 결과를 **검증 테이블**로 정리하여 제시

---

## 검증 테이블 템플릿

최종 결과 제시 시 아래 형식으로 정리:

| 항목번호 | 제목(요약) | 요약 글자수 | 필터링 여부 | 검증 결과 |
|---|---|---|---|---|
| 1 | [제목 또는 "요약 첫 30자..."] | [숫자]자 | Y/N | ✅/❌ |
| 2 | ... | ... | ... | ... |

**검증 결과**:
- ✅: 모든 기준 충족
- ❌: 부족 또는 초과 (사유 명시)

## 주의사항

### 중요
1. **글자 수 정확도**: 공백을 포함하여 정확하게 계산
2. **필터링 기준 숙지**: FILTERING_CRITERIA.md 문서를 먼저 정독
3. **의심의 이익 원칙**: 판정 애매하면 항상 **Y(KEEP)**
4. **원본 수정 금지**: 제목, 작성시각, 본문은 절대 수정 불가

### 작성 팁
- 요약은 **객관적이고 중립적**으로 작성 (평가·의견 불포함)
- 숫자, 날짜, 기업명은 정확하게 기입
- 반복 표현 피하기 (본문에서 그대로 복사하지 않기)
- 한국어 문법·띄어쓰기 검증 필수
